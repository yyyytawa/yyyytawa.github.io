## 1. 社团举办活动前社团方自查

1. 策划案先打印好再去办公室,否则白跑一趟.策划案电子版先发给活动部的人审查,审查过了之后再打印纸质版到办公室继续后面的操作.
   策划案电子版通过审查之后可以提前写好相关表格.
2. 无 PU 和特殊场地的至少提前一周申请,有 PU 或特殊场地的至少提前两周申请.
3. 如果涉及特殊场地请提前填写并打印相关申请表,可以减少办事时间.
   如果未提前打印需要活动部人员现场手写的不要把内容搞得太长,活动部的人要写两遍的!!!~~如果喜欢在办公室多待一会也可以.~~
   也不要太短~~不然保卫处等上级部门可能不给过~~.
4. 商业性活动不给办(学校报备过等特殊白名单除外)

### 需要特殊表格的情况说明

- 教室(不需要打印表格,不需要申请场地)
- 演艺厅、报告厅(需要打印《东校区综合楼演艺厅、报告厅使用申请表》)
- 中心广场、时光里门前广场(需要打印《郑州航院校内活动（校园公共场所）安全管理审批表》)
- 东、西操场、体育场馆(需要打印《郑州航院校内活动（校园公共场所）安全管理审批表》《郑州航空工业管理学院体育场馆使用申请表》《郑州航院体育场馆使用责任书》)
- 大于等于 300 人的活动(《大型活动安全预案》)

提示: 策划案电子版审批通过之后如果涉及特殊场地申请的可以提前填写相关表格电子版并打印,可以和策划案一起带过来.~~减少活动部人员的负担,也可以节约社团人员办事时间.~~特殊表格也可以选择不打印到办公室现场填写.

填写指引和表格文件看表格填写指引部分内容.

## 3. 前往办公室

::: info

学社联办公室一般在工作日 8:30-11:30,14:10-17:30,20:00-21:10 时有人值班.

:::

社团首先前往学社联办公室(01B 4 楼中间的那个,门口有学社联 logo),提交活动本给活动部人员审核,审核通过后填写活动本内容,填写完之后填写其他特殊表格(如提前填写过的可直接交给活动部成员),待全部表格填完统一去盖章.

### 活动发布

1. 基本信息

- 活动名称: 【学生社团联合会｜`<XX>` 社团 `<XX>` 活动】 (注意中间的"｜"是中文的,实在打不出来的就英文+两边各一个空格)
- 发起组织: 校团委
- 承办单位: 无需填写
- 活动级别: 一般院系级,特殊按照实际情况填写
- 活动性质: 第二课堂
- 活动签到员: 搜学号
- 指导老师: 填写学社联
- 活动联系人: 如实填写
- 活动简介: 复制策划案中内容
- 活动须知: 按情况填写

2. 活动信息

- 报名时间: 按照社团要求写
- 活动时间: 按照活动本/策划案填写
- 活动地点: 能直接选的就直接选,实在选不到的可以填个附近的(记得在活动须知里面备注实际地点)或者是直接修改文本
- 活动海报: 学社联 logo

3. 报名信息

- 报名对象范围: 如实填写
- 录取方式: 一般报名评审
- 报名人数: 按照活动本/策划案填写,**除非是真的无限制否则不要不写**
- 报名事项: 保持默认

4. 学分与奖项

::: warning 以下活动不能发放 PU 分

1. 本职工作(如社团的成立，换届大会等)
2. 培训类
3. 有商业性质的活动
4. 比赛参赛人员(有证书)
5. 社团内部人员的活动(没有面向全校师生)
6. 关于第一课堂的内容(老师讲课等)

:::

- 参与角色: 学生
- 积分: 一般填写学生之后会自动获取
- 分配名额: 和报名人数一致

最后提交即可.

发完活动记得到活动审核里面审核,**请仔细核对活动内容,上级审核通过后只能修改活动人数和活动时间,其他内容均不可修改**.

### 活动审核

::: warning

**这个系统所有选择框的全选都是全选当页内容,不是全选所有人员,后续不再重复提醒**

:::

提示: 可以修改单页显示人数

如果录取方式为报名评审的需要到活动管理->活动报名管理->`<活动>`->查看报名名单->全选批量审核通过

提示: 报名快截止前记得登上去看一下,有些人可能会因为各种原因临近截止时退出参与产生空余名额,需要审核新人员填充.

### 活动完结

::: tip 照片要求

在活动过程中,需要用微信小程序: "双亥水印相机"对活动进行拍照用于活动完结,社团拍照前检查水印定位是否为活动地点,如果不是,可以自行修改.水印照片只能用这个水印,否则活动无法完结.

中小型活动,则活动签到人数和水印照片上的人数必须一致,否则活动会因为签到人数与照片人数不符而无法完结.  
大型或流动性活动,则需要在几个时间段内分别拍照,不少于四个时间段,即四张照片.

目前手机端不支持完结活动.

:::

活动认证登记->`<活动>`->认证登记

搜索`已签到`,如果有`未签退`的手动补一下签退,然后全选所有`已签到`人员,点击批量认证,勾选活动加分项,确认.

接着返回上一级,点击认证上报,上传图片,**如果有多张图片需要拼成一张上传,必须保留每张图片的完整内容,尤其是水印**.上传完成之后点击确认等待审核通过后即可完结活动.
