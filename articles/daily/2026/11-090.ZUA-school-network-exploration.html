ZUA 校园网探索

yyyyt2026/11/9大约 5 分钟ZUA

好的又来出这个文章了.

开始之前

起因是 11 月 8 号我登录校园网发现就算是没办校园网套餐也能上网,但是速度只有 4 Mbps,但是一个反常的现象吸引到了我的注意.

全球网测里直接测速是正常的 4 Mbps 的限速,但是!你去体验测速里面-文件下载测速就会发现高德地图和支付宝的下载速度异常的高,高达 100-200 Mbps,speedtest.im 的测速结果也达到了异常的 100 Mbps,这引起了我的注意.于是开始了下面的探索.

1. 部分阿里 CDN 的 IP 不限速

可以明确的是高德地图和支付宝的安装包下载是没限速的,浏览器下载也是差不多的速度,证明确实不是测速软件的 bug.

这些域名都有同样的特点,都是阿里系的而且使用了阿里的 CDN.那么可以首先推测的是学校对阿里的域名/IP 开了白名单所以不限速,经过进一步的实验证明确实是针对特定 IP 的优化.

测速 URL(Speedtest.im 用的): https://gw.alipayobjects.com/os/volans-demo/93211a67-0eed-40ff-8a48-f6c137a88781/MiniProgramStudio-3.1.3.exe?nocache=0.9298986477228943

结论: 此优化针对的是特定 IP,和域名无关.

应用

B 站视频源有阿里 cdn 的源,然后 PiliPlus 那边也能手动选择视频源.所以说其他源速度都是 500 KB/s 的时候那几个阿里源的都干到 6 MB/s 甚至 10 MB/s,当然 alib 除外,这个不在白名单 IP 内.后面 ali 也限速了.

相关猜测

可能是因为学校手机 APP 用的专属版钉钉,为了避免卡顿等情况干脆针对相关 CDN 的 IP 不限速.

2. 内网隔离不完全

经过实测存在简单的 AP 隔离和简单的防火墙规则因为真的很没那么严.

ARP 实测只会显示网关和自己设备,直接 ping 对方 IP 可以 ping 通,直接建立 TCP 和 UDP 连接也能通.内网隔离似乎没那么严.

而且走内网似乎不会计入自助管理系统的总上行流量中不能完全排除不过 BRAS.

3. 路由环路

实测 10.0.0.1/24 存在路由环路问题,第三跳又回到第二跳的地址去了,然后就反复在第二跳和第三跳的路由反复循环直到 TTL 过期被丢弃.

4. 认证网关

学校的认证网关 IP 是 1.1.1.1,经过 ping 测试发现 TTL 为 62,ping 同一个内网其他设备的发现 TTL 为 60,似乎任何流量都是先到认证网关再转发的.

5. 其他

校园网深夜登录会提示夜深了让你注意休息.

学校校园网很会藏路由,只显示前三条.

有线上网 IP 段是 10.13.0.0/16,无线上网 IP 段是 10.15.0.0/16.
